# FPV Flight Simulator

Product page for **FPV Flight Simulator**, a Blender add-on by LarkLab: real-time FPV drone flight in the Blender viewport with RC radios, gamepads or the keyboard.

Live page: https://lucideberry.github.io/FPV-Flight-Simulator/

## Publish

1. Push this folder's contents to the root of the `FPV-Flight-Simulator` repository (`index.html` and the `media` folder at the top level).
2. On GitHub: **Settings > Pages > Build and deployment > Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
3. The page is live at the address above within a few minutes.
4. On Superhive, paste the iframe from `Superhive_embed.txt` into the description in code view (`</>`).
